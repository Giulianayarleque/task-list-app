# 📝 Task List Web App

Una aplicación web sencilla de lista de tareas (To-Do List) construida con HTML, CSS y JavaScript.

Descripción General: Este script permite a los usuarios agregar, marcar y eliminar tareas en una lista de tareas. Utiliza eventos de teclado y clic para interactuar con el DOM.

## 🚀 Funcionalidades

- Agregar tareas nuevas con el botón o presionando Enter.
- Marcar tareas como completadas.
- Eliminar tareas (solo si están completadas).
- Scroll automático si la lista de tareas es muy larga.
- Estilos modernos con diseño responsive.

## 🧱 Tecnologías usadas

- HTML5
- CSS3
- JavaScript (vanilla)
- [Unicons](https://iconscout.com/unicons) para los íconos

## 🛠️ Funcionalidades implementadas:

### Añadir tareas:

- Desde el botón "Add"
- Presionando la tecla Enter
- Valida que no se agreguen tareas vacías


### Marcado de tareas completadas:

- Mediante checkbox
- Aplica un estilo tachado cuando se marca como completada


### Eliminación de tareas:

- Solo permite eliminar tareas ya completadas
- Muestra una alerta si intentas eliminar una tarea no completada


### Gestión del contenedor:

- Añade una clase para permitir scroll cuando hay muchas tareas
